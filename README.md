# Data Liberation Project: Theft/Loss of Controlled Substances

This repository provides the viewer with data compiled by the Data Liberation Project (DLP) from infromation obtained by the U.S. Drug Enforcement Administration (DEA). The raw and restructured files can be accessed and viewed [HERE](https://www.data-liberation-project.org/datasets/dea-theft-and-loss-counts/).

## Code

This repository contained 1 cleaned .csv dataset file and 1 .malloynb file where my code and analysis can be viewed.
  [`chem-quantity-lost.csv](chem-quantity-lost.csv), is the file containing the "tidy" data that was used for analysis.
  [`FavoritoDataLiberation.malloynb`](FavoritoDataLiberation.malloynb), is where my analysis on the Theft/Loss of Controlled Substances was performed and is displayed.

  ## Project Background

  This project is based on the U.S. Drug Enforcement Administration's (DEA) requirement that registrants report any theft or significant loss of controlled substances or listed chemical within one business day. In September 2022, the Data Liberation Project (DLP) filed a Freedom of Information Act request for related database records and documentation. In response, the DEA provided only aggregate spreadsheets and a partially redacted user manual, withholding the detailed report-level data originally requested.

  ## Motivation

  The goal of this analysis is to better understand the patterns and severity of controlled substance losses across the United States. By examining the data across time periods, states, business activities, and types of loss, we aim to identify where and how these losses are occurring most frequently. This can help inform regulatory bodies, healthcare organizations, and policymakers in targeting interventions, improving oversight, and reducing the risk of misuse or diversion of controlled substances. The geographic and temporal visualizations also support regional assessments and trend monitoring over time.

  ## Summary of Findings
  
  This analysis examines controlled substance loss data from 2019 through September 2022, covering reports from 45 U.S. states. The data reveals substantial geographic and temporal variation in the volume of substances lost. A state-by-state breakdown shows notable differences in total losses, with a heat map indicating that some states experience significantly higher losses than others.
  Trends over time, visualized in a bar chart, show fluctuations in the combined loss across the reporting periods. Further breakdowns by loss type (e.g., theft, spillage, or administrative errors) and business activity (such as pharmacies, hospitals, or manufacturers) provide insight into where and how these losses are occurring. The analysis quantifies losses in both milliliters and units, offering a comprehensive view of the scale and nature of controlled substance loss across the U.S.

## Description of how other can build off this work

This analysis provides a foundational framework for exploring controlled substance loss using structured visualizations and aggregated metrics. Others can build on this work by integrating additional datasets—such as population statistics, healthcare provider density, or regulatory actions—to normalize losses and identify potential risk factors.
Further enhancements could include developing time-series analyses to detect trends or anomalies, creating predictive models for future loss patterns, or implementing interactive dashboards for real-time monitoring. Additionally, filtering the data by substance type, geographic region, or specific business categories could support more targeted investigations and policy recommendations.
